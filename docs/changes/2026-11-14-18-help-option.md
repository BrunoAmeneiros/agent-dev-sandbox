# Cambio en la CLI `greet` (Feature 18): `--help` muestra la ayuda

Para operaciones: esta nota corrige la sección "Otras opciones desconocidas: `--help`" de [docs/changes/2026-11-09-16-unknown-options.md](2026-11-09-16-unknown-options.md). Con este cambio, `--help` ya no es una opción desconocida.

| Llamada | Hoy (salida, código) | Ahora (salida, código) |
| --- | --- | --- |
| `--help` | `Unknown option: --help (supported: --lang <code>, --lang=<code>, --shout)`, 2 | el texto de ayuda, 0 |
| `Ana --help` | `Unknown option: --help (supported: --lang <code>, --lang=<code>, --shout)`, 2 | el texto de ayuda, 0 |

Cualquier llamada con `--help` muestra el texto de ayuda, salvo que `--help` sea el valor de `--lang` (`Ana --lang --help` y `Ana --lang=--help`), que sigue siendo un idioma desconocido con salida 2.
